\question{Section 3.3 : 2}{ Let $x_1 > 1$ and $x_{n+1} := 2 - 1/x_n$ for $n \in \mathbb{N}$. show that $(x_n)$ is bounded and monotone. Find the limit. }

\corr{Monotone Sequence} { Let $X=(x_n)$ be a sequence. \begin{itemize} \item $X$ is increasing if $x_1 \le x_2 \le \dots \le x_n \le \dots$. \item $X$ is decreasing if $x_1 \ge x_2 \ge \dots \ge x_n \ge \dots$. \item $X$ is monotone if it is either increasing or decreasing. \end{itemize}}
Note the following relationship:
\[
	1<x_1 \implies \frac{1}{x_1} < 1 \quad \text{Let } \lambda_n:=\frac{1}{x_n}
\]
Observe first few values of $X$: \\
\[
	x_{2} = 2-\lambda_1 \quad x_3 = 2 - \lambda_2  \quad \dots \quad x_n = 2 - \lambda_{n-1}
\]
The nature of the growth/decay of the function is dependent on the values of the $\lambda$ term. \\

Notice (Subproblem A1):
\[
	\begin{gathered}
		\text{Observe }x_1 \in  (1,\infty) \text{ Suppose } x_k \in  (1,\infty) \\
		\implies 1 < x_k  \implies \frac{1}{x_k} < 1 \implies 0 < 1-\frac{1}{x_k} \\
		\implies 1 < 2-\frac{1}{x_k} \equiv  1 < x_{k+1} \\
		\therefore ~\forall~ n \in \mathbb{N}, \text{ by PMI }~x_n \in  \left(  1,\infty\right)
	\end{gathered}
\]

Notice: $x_{k+1} - x_k := \left( 2 - \frac{1}{x_k} \right) - x_k =  \frac{x_k = 2x_k -1 - x_k^2}{x_k} = -\frac{(x_k-1)^2}{x_k}$

Note from Subproblem A1 we can construct  these three statements:
\[
	0<x_n  \quad\quad 0<(x_n-1)^2  \quad -\frac{(x_k-1)^2}{x_k} < 0
\]
As $x_{k+1} - x_k < 0$. This implies $x_{k+1} < x_k$. Thus the sequence is monotonic and decreasing. Therefore a limit must exist.

Recall the limit of the tail of any sequence must converge to the same limit of the sequence as for any sequence we are guarenteed the uniquness of any limit.
\[
	\begin{gathered}
		\implies  \lim_{n \to \infty} x_n = L \implies  \lim_{n \to \infty} x_{n+1} = L \implies  L = 2 - \frac{1}{L} \\
		\therefore  L = 1
	\end{gathered}
\]
