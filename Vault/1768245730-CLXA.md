# Section 2.5 Intervals
## Open, Closed, Half Intervals
The Order Relations on $\mathbb{R}$ determines a collection of subsets called 
"Intervals". 

If $a,b \in \mathbb{R}$ satisfy $a < b$, then the *open interval* deteremined by $a$ and $b$ is the set 
$$
(a,b) := \left\{  x \in \mathbb{R} : a < x = b\right\}
$$

a, b are called the *endpoints* of the intevrval

If both endpoints *are included in the sinterval then we have the* **closed interval**

$$[a,b] := \{ x \in \mathbb{R}: a \leq x \leq b \}$$

If **half-open/half-closed** i.e. $[a,b)$ and $(a,b]$

## Interval Properties
* Bounded and has *length* defined by $b-a$
    * The "Zero Length" Edge Case (a=b)
        * Things get interesting when the starting point and the ending point are the exact same number (e.g., from 5 to 5).
        * The result depends entirely on whether the interval is open or closed.
        * If $a=b$ the corresponidng open interval is the empty set $(a,a) = \emptyset$
    * The corresponding closed interval is the singleton set $[a,a] = \{ a \}$
## Unbounded Intervals
