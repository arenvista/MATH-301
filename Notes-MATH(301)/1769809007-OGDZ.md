# 1.3.12 Theorem: Countable Union of Countable Sets
> [!thm]
> If $A_m$ is a countable set for each $m \in \mathbb{N}$, then the union $A := \bigcup_{m=1}^{\infty} A_m$ is countable.
> 
> > **Simply put:** If you have an infinite list of sets, and every individual set in that list is countable (like the integers), then combining all of them into one giant pile still results in a countable set.
> 
> ---
> 
> ### The Formal Proof
> The text uses a function-based approach to prove this.
> 
> 1.  **Assumption:** For every number $m \in \mathbb{N}$, there is a set $A_m$ that is countable.
> 2.  **Surjection:** Because each $A_m$ is countable, there exists a surjective (onto) function $\varphi_m$ that maps $\mathbb{N}$ onto $A_m$.
> 3.  **Defining a "Master" Map:** We define a new function $\beta : \mathbb{N} \times \mathbb{N} \to A$.
>     * The rule is: $\beta(m, n) := \varphi_m(n)$.
>     * This takes a pair of numbers $(m, n)$ and finds the $n$-th element in the $m$-th set.
> 4.  **Proving Surjection:** The function $\beta$ is a surjection. If you pick any element $a$ inside the big union $A$, it must belong to some specific set $A_m$. Therefore, there are indices $m$ and $n$ such that $a = \varphi_m(n) = \beta(m, n)$.
> 5.  **Using Previous Theorems:**
>     * We know from **Theorem 1.3.10** that the set of pairs $\mathbb{N} \times \mathbb{N}$ is countable.
>     * This means there is a surjection $f: \mathbb{N} \to \mathbb{N} \times \mathbb{N}$.
> 6.  **Conclusion:** By combining these functions ($\beta \circ f$), we get a surjection from $\mathbb{N}$ directly onto $A$. Therefore, $A$ is countable.
> 
> ---
> 
> ### Remark: The "Diagonal Procedure"
> The text offers a visual way to understand why this works, often called Cantor's Diagonal Argument.
> Instead of trying to count all of $A_1$, then all of $A_2$ (which you can't do, because $A_1$ never ends), you arrange the elements in a grid and count diagonally.
> 
> #### The Grid
>  Imagine listing the elements of each set in rows:
> * $A_1 = \{a_{11}, a_{12}, a_{13}, \dots\}$
> * $A_2 = \{a_{21}, a_{22}, a_{23}, \dots\}$
> * $A_3 = \{a_{31}, a_{32}, a_{33}, \dots\}$
> 
> #### The Path
> We enumerate (count) them using a zigzag path:
> 1.  Start at the top left corner: $a_{11}$
> 2.  Move to the next diagonal: $a_{12}, a_{21}$
> 3.  Move to the next diagonal: $a_{13}, a_{22}, a_{31}$
> 4.  Continue this pattern: $a_{14}, \dots$
> 
> #### The Result
> The sequence becomes: $a_{11}, a_{12}, a_{21}, a_{13}, a_{22}, a_{31}, a_{14}, \dots$
> 
> By doing this, you ensure that eventually, every single element $a_{mn}$ in every set is reached, proving the total collection is countable.
