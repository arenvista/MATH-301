# Section 1.3 Finite and Infinite Sets 

> [!def] **Empty Set** 
> The empty set ($\emptyset$) has zero elements. 

> [!def] **Countable Set**:
> A set $S$ has said to have $n$ elements, if there exists a *bijection* from the set of $\mathbb{N}$ onto $S$.

> [!def] **Finite Sets**
> A set is finite if it is either *empty* or *countable*. Conversly if a set is not finite then it is *infinite*.

> [!thm] **Set Sizing**
> Suppose $S,T$ where $T \subset S$ 
> - If $S$ (the larger set) is finite. Then, $T$ (the smaller set) is also finite.
> - If $T$ is infinite. Then $S$ is also infinite.
>
> > [!pf]
> > Suppose $T=\emptyset$, $S \neq \emptyset$
> > We prove by induction on the number $n$ of elements in $S$
> > 1. *Base Case:* If $S$ is a singleton set. Since $T \neq \emptyset$, $T \subset S$. Then $T=S$, then $T$ is finite. 
> > 2. Suppose $S$ has $n$ elements, every nonempty subset of $S$ is finite.
> > 3. Case (n=k+1): Now let $S$ be a set having $k+1$ elements and there exists a bijection from $\{ 1,2,3,...,k+1 \}$ onto $S$
> >     - Let $T \subset S$. If $f(k+1) \neq T$, then $T$ is a subset of $S-\{ f(k+1) \}$ which must have $k$ elements.
> >     - Thus by induction $T$ is a finite set.
> >     - If $f(k+1) \in T$ then $T-\{ f(k+1) \}$ is a subset of $S-\{ f(k+1) \}$. So by induction $T-\{ f(k+1) \}$ is a finite set.
> > Then $T=T-\{ f(k+1) \} \cup \{ f(k+1) \}$
> > 
> > **Note:** There exists a bijection $g: \{ 1,2,3,...,m\}$ onto $T-\{ f(k+1) \}$.
> > - We can define a new bijection $g_a$ from $\{ 1,2,3,..., m, m+1 \}$ onto $T$ by:
> > $$
> > g_a(i)
> > \begin{cases}
> > g(i) \quad \text{If } i=1,2,3,...,m \\
> > g(i) \quad \text{If } i=m+1
> > \end{cases}
> > $$
