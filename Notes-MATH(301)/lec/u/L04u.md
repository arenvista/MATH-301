# Completeness Property

**Recall:** To verify a number is a supremum ($u = \sup S$), we must confirm two things:
1. $u$ is an upper bound of $S$.
2. $u$ is the *least* upper bound of $S$.

> **Strategy:** We can prove this by showing any upper bound is greater than or equal to $u$, or that any number less than $u$ is *not* an upper bound.

Suppose $u$ is a supremum of $S$. The condition that $u$ is the **least** upper bound can be stated as:
* $\forall v < u, \exists s_v \in S \text{ s.t. } v < s_v$

Note the following about this statement:
* It is the negation of "$\forall s \in S, s \leq v$" (which would mean $v$ *is* an upper bound).
* The existence of $s_v > v$ confirms that $v$ is **not** an upper bound of $S$.
* We often rewrite $v$ as $v = u - \epsilon$ for some $\epsilon > 0$.

## Example: Shifted Set Supremum

> [!ex] Theorem: Shifted Set Supremum
> Let $S \neq \emptyset, S \subseteq \mathbb{R}$.
> Define the set $S$ shifted by $a$ as $a+S = \{ s+a \mid s \in S \}$.
>
> **Claim:** $\sup (a+S) = a + \sup S$
>
> > [!pf] Proof
> > Let $u = \sup S$. We want to show $\sup(a+S) = a + u$.
> >
> > > [!case] Case 1: Upper Bound
> > > **Goal:** Show $a + u$ is an upper bound of $a+S$.
> > > ie: $\forall x \in (a+S), x \leq a + u$.
> > >
> > > *Analysis (Backward Search):*
> > > 1. $\iff a+s \leq a + \sup S$
> > > 2. $\iff s \leq \sup S$ (True by definition)
> > >
> > > *Formal Proof:*
> > > 1. Since $u = \sup S$, $u$ is an upper bound of $S$.
> > > 2. Therefore, $\forall s \in S, s \leq u$.
> > > 3. Adding $a$ to both sides preserves the inequality: $s+a \leq a + u$.
> > > 4. Thus, $a + u$ is an **upper bound** of $a+S$.
> >
> > > [!case] Case 2: Least Upper Bound
> > > **Goal:** Show that if $v$ is any upper bound of $a+S$, then $a + u \leq v$.
> > >
> > > *Analysis (Backward Search):*
> > > 1. $\iff a + \sup S \leq v$
> > > 2. $\iff \sup S \leq v - a$
> > > 3. $\iff v - a$ is an upper bound of $S$
> > > 4. $\iff \forall s \in S, s \leq v - a$
> > > 5. $\iff \forall s \in S, s + a \leq v$ (True by supposition)
> > >
> > > *Formal Proof:*
> > > 1. Suppose $v$ is an arbitrary upper bound of $a+S$.
> > > 2. By definition, $\forall x \in (a+S), x \leq v$.
> > > 3. Substituting $x = s+a$, we have $\forall s \in S, s+a \leq v$.
> > > 4. Subtracting $a$ yields: $\forall s \in S, s \leq v-a$.
> > > 5. This implies that $(v-a)$ is an upper bound of $S$.
> > > 6. Since $u = \sup S$ is the *least* upper bound, it must be that $u \leq v-a$.
> > > 7. Therefore, $a + u \leq v$.
> >
> > **Conclusion:** Since $a + \sup S$ is an upper bound and it is less than or equal to any other upper bound, $\sup(a+S) = a + \sup S$.

## Scaled Set Supremum

> [!imp] Practice: Scaled Set Supremum
> Consider the set $aS = \{ as \mid s \in S \}$.
>
> > [!note] Definition: $\sup(aS)$
> > $$
> > \sup(aS) =
> > \begin{cases}
> > a \cdot \sup S & \text{If } a > 0 \\
> > a \cdot \inf S & \text{If } a < 0
> > \end{cases}
> > $$

### Example: Set Comparison

> [!ex] Proposition
> **Prove:** If $\forall a \in A, \forall b \in B, a \leq b$, then $\sup A \leq \inf B$.
>
> *Analysis:*
> 1. $\sup A \leq \inf B$
> 2. $\iff \inf B$ is an upper bound of $A$
> 3. $\iff \forall a \in A, a \leq \inf B$
> 4. $\iff \forall a \in A, a$ is a lower bound of $B$
> 5. $\iff \forall b \in B, \forall a \in A, a \leq b$ (Given)
>
> **Formal Proof:**
> 1. Fix an arbitrary $a \in A$.
> 2. We are given that $\forall b \in B, a \leq b$.
> 3. By definition, this means $a$ is a lower bound for the set $B$.
> 4. By definition of infimum, $\inf B$ is the *greatest* lower bound.
> 5. Therefore, $a \leq \inf B$.
> 6. Since this holds for any arbitrary $a \in A$, $\inf B$ is an upper bound for the set $A$.
> 7. By definition of supremum, $\sup A$ is the *least* upper bound.
> 8. Therefore, $\sup A \leq \inf B$.

# Completeness and Archimedean Properties

> [!def] Completeness Property of $\mathbb{R}$
> Every nonempty subset $A \subseteq \mathbb{R}$ that is bounded above has a supremum in $\mathbb{R}$.
> (Similarly, every nonempty subset bounded below has an infimum in $\mathbb{R}$.)

## The Archimedean Property

> [!thm] Theorem
> For any $x \in \mathbb{R}$, there exists a natural number $n_x$ larger than $x$.
> $$x \in \mathbb{R} \implies \exists n_x \in \mathbb{N} \text{ s.t. } x < n_x$$
>
> > [!pf] Proof
> > Suppose for the sake of contradiction that the statement is false.
> > $\exists x \in \mathbb{R}$ such that $\forall n \in \mathbb{N}, x \geq n$.
> >
> > 1. This implies $x$ is an upper bound of $\mathbb{N}$.
> > 2. Since $\mathbb{N} \subseteq \mathbb{R}$ and $\mathbb{N} \neq \emptyset$, by the **Completeness Property**, $\sup \mathbb{N}$ exists. Let $u = \sup \mathbb{N}$.
> > 3. Since $u$ is the *least* upper bound, $u-1$ is **not** an upper bound of $\mathbb{N}$.
> > 4. Therefore, $\exists m \in \mathbb{N}$ such that $u-1 < m$.
> > 5. Rearranging, we get $u < m+1$.
> > 6. Since $m \in \mathbb{N}$, $m+1 \in \mathbb{N}$ (by closure of addition).
> > 7. We have found an element ($m+1$) in $\mathbb{N}$ that is strictly greater than the supremum $u$.
> >
> > **Contradiction:** $u$ cannot be an upper bound if there is an element greater than it. Thus, $\mathbb{N}$ is not bounded above.

### Corollaries

> [!cor] Infimum of Reciprocals
> Let $S = \{ \frac{1}{n} \mid n \in \mathbb{N} \}$. Then $\inf S = 0$.
>
> > [!pf] Proof
> > We must satisfy two conditions:
> > 1. $0$ is a lower bound.
> > 2. $0$ is the *greatest* lower bound.
> >
> > > [!case] Part 1: Lower Bound
> > > We want to show $\forall n \in \mathbb{N}, \frac{1}{n} \geq 0$.
> > > Since $n \in \mathbb{N}, n \geq 1 > 0$. The quotient of two positive numbers is positive.
> > > Thus, $\frac{1}{n} > 0$.
> >
> > > [!case] Part 2: Greatest Lower Bound
> > > We show that for any $\epsilon > 0$, $\epsilon$ is *not* a lower bound of $S$.
> > > 1. Let $\epsilon > 0$. Then $\frac{1}{\epsilon} \in \mathbb{R}$.
> > > 2. By the **Archimedean Property**, there exists $n \in \mathbb{N}$ such that $n > \frac{1}{\epsilon}$.
> > > 3. Inverting the inequality (since both sides are positive): $\frac{1}{n} < \epsilon$.
> > > 4. Since $\frac{1}{n} \in S$, there is an element in $S$ smaller than $\epsilon$.
> > > 5. Thus, $\epsilon$ is not a lower bound.
> >
> > **Conclusion:** Since $0$ is a lower bound and no number greater than $0$ is a lower bound, $\inf S = 0$.

> [!cor] Density of Unit Fractions
> $$\forall t \in \mathbb{R}, t > 0 \implies \exists n \in \mathbb{N} \text{ s.t. } 0 < \frac{1}{n} < t$$
> *(This is a direct application of the previous corollary).*

> [!cor] Bounding Real Numbers
> For any real number $y > 0$, there exists a natural number $n$ such that $n-1 \leq y < n$.
>
> > [!pf] Proof Sketch
> > Consider the set $E = \{ m \in \mathbb{N} \mid y < m \}$.
> > 1. By the **Archimedean Property**, $E \neq \emptyset$.
> > 2. By the Well-Ordering Principle, $E$ has a smallest element, denoted $n_y$.
> > 3. Since $n_y \in E$, we have $y < n_y$.
> > 4. Since $n_y$ is the *smallest* element in $E$, $n_y - 1 \notin E$.
> > 5. Therefore, $n_y - 1 \leq y$.
> >
> > Combining these gives: $n_y - 1 \leq y < n_y$.
