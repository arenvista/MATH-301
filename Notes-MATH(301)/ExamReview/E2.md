# Exam 2: Breakdown of $\epsilon-\delta$ Proofs

> [!?] Prove: $\lim_{x \to 1} \frac{x^2 -x +1}{x+1} = \frac{1}{2}$

## Backward Search 

Recall: To prove a $\epsilon-\delta$ proof we need to justify the following.
$$ \forall~ \epsilon \in \mathbb{R} ~.~  \epsilon > 0, \exists~ \delta_\epsilon ~.~ \forall~ x ~.~ 0 < |x-c| < \delta_\epsilon, ~|f(x) - L| < \epsilon $$ 

We can break this down as follows:
* $\forall~ \epsilon > 0 \equiv$ "For every tolerance called $\epsilon$"
* $\exists~ \delta_\epsilon \equiv$ "There is a coresponding distance called $\delta$"
* $\forall~ x ~.~ 0<|x-c|<\delta \equiv$ "Such that for every value $x$ within $c \pm \delta$", excluding $c$ itself
    * _Note: we exclude $c$ as for limit convergence the value of $c$ is unimportant the the "behavior" of the function_
* $|f(x) - L| < \epsilon \equiv$ "The values of the image of $x$ are within the tolerance $\epsilon$"

We can use these facts to find a coresponding $\delta$ that works by gleaming at some of the information we want to hold in the forward proof construction.

### Restricting $\delta$ 
Before we can find a proposed $\delta$ we should see what values of $x$ can't work.
- Look out for things like divisions by zero 

In this case the $\delta$ neghborhood is centered at $c=1$. So we must ensure that the $\delta$-neghborhood does not go so far left as to include $-1$. Otherwise $x=-1$ as we have a $x+1$ defined on the denominator of the function.

Now how do we know what delta to pick? We are given some freedom as we just have to justify _some_ $\delta$ works for each $\epsilon$ - provided it upholds our restrictions we defined. So why don't we pick an easy one and see if it works.

### Picking a proposed $\delta$

Since for our given problem we are concered with $\lim_{x \to 1}$ we can say:
$$ |x-1| < \delta $$ 

By the properties of absolute value we know:
$$ -\delta < x-1 < \delta $$ 

By our restriction above this works so long as $\forall~ x, x \neq -1$. 
We can improve this a little bit more though. Recall $\delta$ really expands to $-\delta+1 < x < \delta+1$  so we just have to ensure $-\delta+1 \neq -1$

> [!tip] Visual Intuition
> If you want to think about this pictorally consider that $c$ is the center where $-\delta+c$ is the left endpoint  and $\delta+c$ is the right endpoint (non-inclusive). As $c=1$, we know the center of our $\delta$-neghborhood is one. If $x$ can't be $-1$ then we know that $-\delta+c$ must be ***strictly greater than*** negative one.

>[!?] Guiding Question
> So can think of the following inequality ($c=1$):
> $$ -1 < -\delta + 1 < x < \delta +1 $$ 
> Now we must think: "What are some easy values of $\delta$ that make this work"?
> - An easy value that upholds the inequality is $\delta=1$.

Let $\delta=1$, observe:
$$
\begin{align}
& -1 < -\delta + 1 < x < \delta +1 \\
& \implies  -1 < (-1)+1 < x < 1+1 \\
& \implies -1 < 0 < x < 1 \\
\end{align}
$$ 

Since we uphold our restriction of $-1 < \delta + c$ we get these nice bounds for $x$. So now we have some information about the values of $x$ we actually care to show works so that $|f(x) - L| < \epsilon$.

### Relating $\delta$ to $\epsilon$

Now how can we guarentee that the values of $x$ for our given $\delta$, that is all $x \in (0,2)$, actually work to show our $\epsilon$ restriction?

We can work backwards from the $\epsilon$ definition we are trying to prove to find a term that we can use to show the relationship between the two.

Well we already know from the $\delta$ definition that:
$$ |x-1| < \delta $$ 

Recall we are trying to prove the $\epsilon$ restriction of:
$$ \left| \frac{x^2-x+1}{x+1} - \frac{1}{2} \right| < \epsilon $$ 

So if we can isolate the left hand to a bounding term, let's call it $M$ and $|x-1|$ then we get the following:
$$M |x-1| < \epsilon $$ 

Since $|x-1| < \delta$ we have a nice way of relating our $\epsilon$ definition to the $x$ values we obtained from our proposed "trial" $\delta$ 

Observe the following

| Expression                                                       | Reasoning                                          |
|------------------------------------------------------------------|----------------------------------------------------|
| $\mid \frac{x^2-x+1}{x+1} - \frac{1}{2} \mid < \epsilon$         | Infered (Backwards Search)                         |
| $\mid \frac{2x^2-2x+2}{2x+2} - \frac{x+1}{2x+2} \mid < \epsilon$ | Finding Common Denominator                         |
| $\mid \frac{2x^2-3x+1}{2x+2} \mid < \epsilon$                    | Simplify Common Terms                              |
| $\mid \frac{(-2x+1)(-x+1)}{2x+2} \mid < \epsilon$                | Factorize                                          |
| $\mid \frac{-(2x-1) \times -(x-1)}{2x+2} \mid < \epsilon$        | Pull out negative                                  |
| $\mid \frac{(2x-1) (x-1)}{2x+2} \mid < \epsilon$                 | Double Negative to Positive                        |
| $\mid \frac{(2x-1) \textbf{(x-1)}}{2x+2} \mid < \epsilon$        | Notice the bold is exactly what we are looking for |
| $\mid \frac{2x-1 }{2x+2} \mid \times \mid x-1 \mid < \epsilon$                | Triange Inequality                                 |

Now refering to above observe the following
$$
\underbrace{\left| \frac{2x-1 }{2x+2} \right|}_{Nuissance ~ Term} ~|x+1| < \epsilon
$$ 
We have found $|x+1|$ along with some "nuissance term". We can't just take $\epsilon$ in terms of this as this term contains variable $x$ terms. 

The neat thing is though is that if the function truly does converge to some limit then this extra term must logically also be bounded by something, we called this $M$ earlier. So let's formailize it. 

$$ \left| \frac{2x-1 }{2x+2} \right| < M $$ 

### Defining the Bonding Term $M$

We want nice constant terms for $M$ so we can use it to validate the $\epsilon$ restriction.

The tricky part here is that there's really two criteria we have to prove. We must consider for over given $x_\delta \in (0,2)$ 
1. What's the possible values of the numerator $2x_\delta-1$ considering $x_\delta \in (0,2)$
1. What's the possible values of the denominator $2x_\delta+2$ considering $x_\delta \in (0,2)$


> [!tip] Maximize the Bound
> Keep in mind we want to make our bond here as large as possible:
> Consider $\exists~ M_1, M_2 \in \mathbb{R} ~.~ M_1 < M_2$
> $$ M_1 < M_2 \implies M_1 |f(x) - L| < M_2 |f(x) - L| $$ 
> This way we show the following inequalities hold
> $$ M_2 |f(x) - L|  < \epsilon \implies  M_1 |f(x) - L| < \epsilon $$ 

#### Finding the numerator
We want to use $0 < x < 2$ and express it in terms of $2x-1$
$$
\begin{aligned}
    0 &<\quad\quad\quad x   &&< 2 \\
    0 &<\quad\quad\quad 2x  &&< 4 \\
   -1 &<\quad\quad\quad 2x-1 &&< 3 \\
\end{aligned}
$$

To maximize the size of the bound we want the numerator to be as large as possible so let it be 3.

#### Finding the denominator
We want to use $0 < x < 2$ and express it in terms of $2x+2$

$$
\begin{aligned}
    0 &<\quad\quad\quad x   &&< 2 \\
    0 &<\quad\quad\quad 2x  &&< 4 \\
   2 &<\quad\quad\quad 2x+2 &&< 6 \\
\end{aligned}
$$

To maximize the size of the bound we want the denominator to be as small as possible so let it be 2.

##### Putting it Together

Thus we have the bonding term $M := \frac{3}{2}$. Notice the relationship to the "nuissance term".
$$
\left| \frac{2x-1 }{2x+2} \right| < \frac{3}{2} = M
$$ 

#### Finding the $\delta_\epsilon$

Now let's use this $M$ to find $\delta$ in terms of $\epsilon$
$$ M |x-1| < \epsilon \implies  \frac{3}{2} |x-1| < \epsilon  \implies | x-1 | < \frac{2 \epsilon}{3} $$ 

$$ \text{Really notice the expression: } \quad | x-1 | < \frac{2 \epsilon}{3} $$ 

Recall from the $\delta$-definition we know:
$$ | x-c | < \delta $$ 

Thus for a $c=1$ we can use $\frac{2\epsilon}{3}$ as a $\delta$!

### The Mechanics of an $\epsilon-\delta$ Proof

Keep in mind the fundamental relationship in an $\epsilon-\delta$ proof: we are given a tolerance for the $y$-values (denoted by $\epsilon$), and our job is to find a corresponding restriction on the $x$-values (denoted by $\delta$) that guarantees that tolerance is met. 

1. **The Target Bound:** We want the values of $f(x)$ to fall within the interval $(L-\epsilon, L+\epsilon)$. This is written as $|f(x) - L| < \epsilon$.
2. **The Required Restriction:** To guarantee this, we must restrict $x$ to fall within the interval $(c-\delta, c+\delta)$, explicitly excluding $c$ itself. 

Recall that the $x$-values we care about are not all real numbers, but rather only the $x$-values within this punctured interval:
$$x \in (c-\delta, c) \cup (c, c+\delta)$$
Mathematically, this is expressed as $0 < |x - c| < \delta$, which ensures $x$ gets infinitely close to $c$ without actually being $c$.

### The "Minimum of Two Deltas" Strategy

In many proofs (especially for non-linear functions), finding a single, clean expression for $\delta$ is difficult because the algebraic factors fluctuate depending on $x$. To solve this, we establish *two* conditions for $\delta$ that must be met simultaneously:

1. **An Arbitrary Constant Bound (e.g., $\delta \le 1$):** We temporarily lock $x$ into a fixed, finite interval around $c$ (usually a distance of 1). By doing this, we can find the maximum possible size for any troublesome algebraic factors that depend on $x$.
2. **An $\epsilon$-Dependent Bound (e.g., $\delta \le \frac{2\epsilon}{3}$):** Using the maximum size we found in step 1, we can calculate a second restriction for $\delta$ that guarantees our $f(x)$ values stay within the $\epsilon$ tolerance.

**How do we ensure both conditions are satisfied?** We define our final $\delta$ by taking the stricter (smaller) of the two values: 
$$\delta = \min \left( 1, \frac{2\epsilon}{3} \right)$$

- **Why this works:** By taking the minimum, we guarantee that the $x$-values respect *both* the arbitrary neighborhood we created to simplify the algebra (the $1$) *and* the calculated tolerance required to satisfy the limit (the $\frac{2\epsilon}{3}$). 
- **Why we are allowed to do this:** The definition of a limit simply requires us to find *at least one* valid $\delta > 0$. If a certain $\delta$ radius successfully keeps $f(x)$ within $\epsilon$, then any *smaller* radius will naturally do the exact same thing. Shrinking our window to the smaller of the two bounds is always mathematically legal.

Recall, we obtainied the following $\delta=1$ and $\delta=\frac{2\epsilon}{3}$ from the following:
1. $\delta=1$ was used to define the distance $x$ is allowed to stray from $c$
2. $\frac{2\epsilon}{3}$ was used to define the values of $x$ that ensure we never escape the tolerance

This works as for a ridicoulsly small $\epsilon$ then our $\delta=1$ will no longer hold so we can fallback to our $\delta := \frac{2\epsilon}{3}$
