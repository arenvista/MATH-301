# Chapter 1.3 - Finite and Infinite Sets
> [!def]
> ## Finite and Infinite Sets
> * The $\emptyset$ (empty set) is said to have zero elements.
> * If $n \in \mathbb{N}$, a set $S$ is said to have $n$ **elements** if there exists a bijection from the set $\mathbb{N}_n := \{ 1,2,...,n \}$ onto $S$
> * A set $S$ is said to be **finite** if it is either empty or it has $n \in \mathbb{N}$ elements.
> * A set $S$ is said to be **infinite** if it is not finite.

> [!thm]
> ## [Uniquness Theorem (1.3.2)](1769807822-DOEP.md): 
> *If $S$ is a finite set, then the number of elements in $S$ is a unique number in $\mathbb{N}$*

> [!thm]
> ## Theorem (1.3.4) [Principle of Inclusion-Exclusion (Adapted)](1769807871-FKBW.md):
> * If $A$ is a set with $m$ elements and $B$ is a set with $n$ elements if $A \cap B = \emptyset$, then $A \cup B$ has $m+n$ elements
> * If $A$ is a set with $m \in \mathbb{N}$ elements and $C \subseteq A$ is a singlton set. Then $A-C$ is a set with $m-1$ elements.
> * If $C$ is a infinite set and $B$ is a finite set. Then $C-B$ is an infinite set. 
> ---
> **Form (Without Overlap):** 
>  $$|A \cup B| = |A| + |B| = m + n$$
> **General Form (With/Without Overlap):** 
> $$|A \cup B| = |A| + |B| - |A \cap B|$$

> ## [Inifintude of Subset Relations (1.3.5)](1769807924-LDGZ.md)
> Suppose that $S,T$ are sets and that $T \subseteq S$
> - $S$ is a finite set $\implies T$  is a finite set.
> - $T$ is an infinite set $\implies S$ is an infinite set. 

> [!def]
> ## [Countable Set](1769807947-AZTA.md)
> Given a set $A$ and $B \subseteq \mathbb{N}$
> - $A$ is said to be **countable** if there exists a bijection $f: B \rightarrow A$
> - Else it is said to be **uncountable**

> [!def] 
> ## [Denumerable](1769807964-EKVE.md)
> If the set is *countable* AND *infinite* it is **denumerable**

> [!pf]
> ### Informal Proof: [The set $\mathbb{N} \times \mathbb{N}$ is denumerable. (1.3.8)]
> *See this [video](https://www.youtube.com/watch?v=0HF39OWyl54) for more context.*
> **The Goal:**
> To map all ordered pairs $(m,n)$ where $m,n \in \mathbb{N}$ to a single sequential list:
> $$(1,1), (1,2), (2,1), (1,3), (2,2), (3,1), (1,4), \dots$$
>
> **The Method (Diagonal Map):**
> We cannot count by rows because rows are infinite. Instead, we generate the list using a **diagonal procedure**:
> ![diag.png | center | 200](assets/imgs/diag.png)
>
> **Step 1: Observe the Diagonal Pattern**
> Note the number of points in each specific diagonal:
> - **1st diagonal:** 1 point [(1,1)]
> - **2nd diagonal:** 2 points [(1,2), (2,1)]
> - **$k$-th diagonal:** $k$ points
>
> To count how many points exist in the first $k$ diagonals combined, we use the triangular number formula $\psi(k)$:
> $$\psi(k) = 1 + 2 + \dots + k = \frac{k(k+1)}{2}$$
>
> **Step 2: Locate a specific point $(m, n)$**
> To find the exact list position (index) of a pair $(m,n)$:
> 1.  **Find the Diagonal:** The point lies in the **$(m+n-1)$-th** diagonal.
> 2.  **Count Previous Points:** We first count all points in the *previous* $m+n-2$ diagonals using the formula above.
> 3.  **Add Current Offset:** We add $m$ to represent the point's specific position within its own diagonal.
>
> **Step 3: The Final Formula**
> Combining these observations gives the bijection function $h(m,n)$:
> $$h(m,n) = \frac{(m+n-2)(m+n-1)}{2} + m$$

> [!thm]
> ## [1.3.12 Theorem: Countable Union of Countable Sets](1769809007-OGDZ.md)
> If $A_m$ is a countable set for each $m \in \mathbb{N}$, then the union $A := \bigcup_{m=1}^{\infty} A_m$ is countable.
> 
> > **Simply put:** If you have an infinite list of sets, and every individual set in that list is countable (like the integers), then combining all of them into one giant pile still results in a countable set.
> 
> ---
> 
> ### The Formal Proof
> The text uses a function-based approach to prove this.
> 
> 1.  **Assumption:** For every number $m \in \mathbb{N}$, there is a set $A_m$ that is countable.
> 2.  **Surjection:** Because each $A_m$ is countable, there exists a surjective (onto) function $\varphi_m$ that maps $\mathbb{N}$ onto $A_m$.
> 3.  **Defining a "Master" Map:** We define a new function $\beta : \mathbb{N} \times \mathbb{N} \to A$.
>     * The rule is: $\beta(m, n) := \varphi_m(n)$.
>     * This takes a pair of numbers $(m, n)$ and finds the $n$-th element in the $m$-th set.
> 4.  **Proving Surjection:** The function $\beta$ is a surjection. If you pick any element $a$ inside the big union $A$, it must belong to some specific set $A_m$. Therefore, there are indices $m$ and $n$ such that $a = \varphi_m(n) = \beta(m, n)$.
> 5.  **Using Previous Theorems:**
>     * We know from **Theorem 1.3.10** that the set of pairs $\mathbb{N} \times \mathbb{N}$ is countable.
>     * This means there is a surjection $f: \mathbb{N} \to \mathbb{N} \times \mathbb{N}$.
> 6.  **Conclusion:** By combining these functions ($\beta \circ f$), we get a surjection from $\mathbb{N}$ directly onto $A$. Therefore, $A$ is countable.
> 
> ---
> 
> ### Remark: The "Diagonal Procedure"
> The text offers a visual way to understand why this works, often called Cantor's Diagonal Argument.
> Instead of trying to count all of $A_1$, then all of $A_2$ (which you can't do, because $A_1$ never ends), you arrange the elements in a grid and count diagonally.
> 
> #### The Grid
>  Imagine listing the elements of each set in rows:
> * $A_1 = \{a_{11}, a_{12}, a_{13}, \dots\}$
> * $A_2 = \{a_{21}, a_{22}, a_{23}, \dots\}$
> * $A_3 = \{a_{31}, a_{32}, a_{33}, \dots\}$
> 
> #### The Path
> We enumerate (count) them using a zigzag path:
> 1.  Start at the top left corner: $a_{11}$
> 2.  Move to the next diagonal: $a_{12}, a_{21}$
> 3.  Move to the next diagonal: $a_{13}, a_{22}, a_{31}$
> 4.  Continue this pattern: $a_{14}, \dots$
> 
> #### The Result
> The sequence becomes: $a_{11}, a_{12}, a_{21}, a_{13}, a_{22}, a_{31}, a_{14}, \dots$
> 
> By doing this, you ensure that eventually, every single element $a_{mn}$ in every set is reached, proving the total collection is countable.
