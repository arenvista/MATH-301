# Cauchy Criterion

## Cauchy Definition
A sequence $X=(x_n)$ is "cauchy" if:

$$
\begin{gathered}
\forall~ \epsilon > 0, \exists~ h_\epsilon > 0 ~\text{ s.t. }  \\
\forall~ h_\epsilon \leq m,n, \quad |x_n - x_m| < \epsilon
\end{gathered}
$$

We are saying: at some index $h_\epsilon$, the distance between two elements $x_m, x_n$ will be small.

## Example

Prove: $x_n = (\frac{1}{n})$ is cauchy.

$$
	\begin{gathered}
		|\frac{1}{n}- \frac{1}{m} | < \epsilon \\
		\frac{1}{n} + \frac{1}{m}   < \epsilon \leftarrow
		\begin{cases}
			\frac{1}{m} < \epsilon/2 \\
			\frac{1}{n} < \epsilon/2
		\end{cases} \leftarrow
		\begin{cases}
			n > 2/\epsilon \\
			m > 2/\epsilon
		\end{cases} \\
		\leftarrow  \exists~ h_\epsilon > 2/\epsilon
	\end{gathered}
$$


## Negation
Example: $x=(-1)^n$ is not cauchy.
$$
    h_\epsilon \leq m,n \implies \exists~ \epsilon_0 > 0, \forall~ k \in \mathbb{N}, \exists~  m_k, n_k \text{ s.t. } |x_{m_k} - x_{n_k} | \geq \epsilon
$$ 

Notice: $|(-1)^n - (-1)^{n+1} | = 2$ so we can pick any $\epsilon < 2$ to validate the negation.
$$
\begin{gathered}
\text{Let } \epsilon_0 = 1, \forall~ k \in  \mathbb{N} \\
\text{Let } n_k = k, m_k = k+1 \implies  k \leq m_k, ~k \leq n_k \\
|x_{k+1} - x_k | \not > 1 \\
\therefore ~x_n \text{ is not cauchy.}
\end{gathered}
$$ 

## Thm: Cauchy Converge Criterion
A sequence $x_n$ is convergent IFF it is Cauchy.
### Proof ($\rightarrow$)
$$
\begin{gathered}
|x_n - x| < \epsilon \implies  \\
|x_n - x_m| < \epsilon \implies \\
|x_n -x_m| = |x_n - x + x - -x_m | \implies  \\
|x_n -x_m| \leq  |x_n - x| + |x_m - x | \\
|x_n -x_m| \leq  \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon \\
\end{gathered}
$$ 

Putting it together: 
1. $\forall~ \epsilon>0, \exists~ n_\epsilon > 0$ s.t. $\forall~  n \geq n_\epsilon, ~|x_n-x| < \epsilon/2$
2. Thus, $\forall~  h_\epsilon \leq m,n, |x_n-x|<\epsilon/2$ and  $|x_m - x | < \epsilon/2$. 
3. So $|x_n - x| + |x_m -x| < \epsilon$. Thus $x_n$ is Cauchy.

### Proof ($\leftarrow$)
1. Goal: Show $\{ x_n \}$ is bounded. 
- Since $x_n$ is Cauchy:
    - Let $\epsilon=1,~ \exists~ h_1$ s.t. $\forall~ h_1 \leq m,n  ~~|x_n - x_m| < 1$
    - Isolate for just one index: $\forall~ h_1 \leq n  ~~|x_n - x_{h_1}| < 1$
Apply Triange Inequality: 
- $\forall~ h_1 \leq n,~ |x_n| \leq  |x_n - x_{h_1} + |x_{h_1}| < 1 + |x_{h_1}|$
Bring it together: 
- Let $M = max \{ |x_1|, |x_2|, ~\dots,~ |x_{h_1-1}|, ~1+|x_{h_1}| \}$.
- Then  $|x_n| \leq  M ~\forall~ n \in  \mathbb{N}$. Therefore $\{ x_n \}$ is bounded.

---

2. Since $x_n$ is bounded, by [The Bolzano–Weierstrass Theorem](Atomized/H1/The%20Bolzano–Weierstrass%20Theorem.md) $\exists~ $ a convergent subsequence $(x_{n_k}) \inf(x_n)$. Let $\lim_{k \to \infty} x_{n_k} = L_k$.

---

3. Show that $L_k$ is the limit of $x_n$
Since $x_n$ is cauchy, $\forall~ \epsilon>0, \exists~  h_{\epsilon/2}$ s.t. $\forall~  m,n \geq h_{\epsilon/2}, ~~|x_n-x_m| < \epsilon/2$
Since $\lim x_{n_k} = L_k$. Then $\exists~ k_{\epsilon/2}$ s.t. $|x_{n_k} - L_k| < \epsilon/2, ~~\forall~ k \geq  k_{\epsilon/2}, ~~n_k \geq h_{\epsilon/2}$
So $\forall~ h_{\epsilon/2} \leq n, ~~ |x_n-L| \leq |x_n - x_{n_k}| + |x_{n_k} - L| < \epsilon$ 

$$
\begin{gathered}
\text{Choose $k \geq k_{\epsilon/2}$ so that the following below hold as well:} \\
\forall~ h_{\epsilon/2} \leq n, ~~ |x_n-L| \leq \underbrace{|x_n - x_{n_k}|}_{\text{Should be $< \epsilon/2$}} + \underbrace{|x_{n_k} - L|}_{\text{Should be $< \epsilon/2$}} < \epsilon
\end{gathered}
$$ 
This will work for some $k$ provided it's large enough.

### Example
**Question**: Consider $x_n := 1 + 1/2 + 1/3 + \dots + 1/n$ diverges. How can we proove this?
**Response**: We can do this by showing $x_n$ is not Cauchy
$$
\begin{gathered}
\exists~ n_k,m_k \geq k \text{ s.t. } |x_{n_k} - x_{m_k}| \geq \epsilon \\
\text{Note: } n>m \implies x_n - x_m = \frac{1}{m+1} + \frac{1}{m+2} + \dots + \frac{1}{n} \\
\text{Let } n=2m \implies  x_n - x_m \geq \frac{1}{2m} + \frac{1}{2m}  + \dots + \frac{1}{2m}  \text{ (note there are $m$ terms)} \\
\$text{Note: } \equiv  x_n-x_m \geq \frac{1}{2} = m\left( \frac{1}{2m} \right) 
\end{gathered}
$$ 

In other words: 
If $\epsilon = 1/2$ we can let $n_k = k, m_k = 2k$. 
Then $m_k,n_k \geq k$ and $|x_{n_k}-x_{m_k}|  > k \frac{1}{2k} = \frac{1}{2}-\epsilon$ Therefore $x_n$ is not Cauchy.

Def Contractive
$x_n$ is "contractive" if there exists a contant $c, 0<c<1$ s.t.
$$ \forall~ \text{sufficently large }n, |x_{n_k} - x_{m_k}| \leq  c|x_{n+1} - x_n| $$ 

Example: 
$$
x_n:=
\begin{cases}
    x_1 = 1 \\
x_2 = 2 \\
x_n = \frac{1}{2}(x_{n-1} + x_{n-2})
\end{cases}
$$

Observe
$$
\begin{gathered}
x_{n+2}-x_{n+1} = \frac{1}{2}(x_{n+1} + x_n) - x_{n+1} = \frac{1}{2} x_n - \frac{1}{2} x_{n+1} = \frac{1}{2}(x_n-x_{n+1}) \\
|x_{n+2}-x_{n+1}| = \frac{1}{2}|x_n - x_{n+1}| = \frac{1}{2}|x_{n+1} - x_n| \\
\text{So $x_n$ is a contractive sequence}
\end{gathered}
$$ 

Thm: 
Every Contractive Sequence is Cauchy and therefore is convergent. 

Proof: 

$$ |x_{n+2} x_{n+1}| \leq  c |x_{n+1} - x_n| \leq  c \cdot c \cdot |x_n - x_{n-1}| \leq \dots \leq c \cdot c \cdot \dots \cdot c |x_2 - x_1| $$ 
$$ \text{Note: } c \cdot c \cdot \dots \cdot c |x_2 - x_1| = c^n |x_2 - x_1| $$ 

$$
\begin{align}
|x_n -x_m| & = \\
& \leq |x_n-x_{n-1}| + |x_{n-1}+x_{n-2}| + \dots |x_{m+1}-x_m| \\
& \leq c^{n-2} |x_2 -x_1| + c^{n-3} |x_2-x_1| + \dots + c^{m-1}|x_2-x_1| \\
&  = |x_2-x_1| (c^{n-2}+c^{n-3}+\dots+c^{m-1})\\
& = c^{m-1}|x_2-x_1|(c^{n-m-1}+\dots +1)
\end{align}
$$ 


Note: 
$$
\begin{gathered}
s_n = 1 + a + a^2 + \dots + a^n = ~? \\
a \cdot s_n = a + a^2 + \dots + a^{n+1} \\
(1-a) s_n = 1-a^{n+1} \\
\implies s_n = \frac{1-a^{n+1}}{1-a}
\end{gathered}
$$ 

Thus:
$$
\begin{gathered}
=c^{m-1}|x_2-x_1| \left( \frac{1-c^{n-m}}{1-c} \right)  \\
= \frac{|x_2 - x_1|}{1-c} (c^{m-1}-c^{n-1}) <\epsilon
\end{gathered}
$$ 

## Example
Let $x_n$ be defined by:
$$ x_n := \begin{cases} x_1 = 1 \\ x_{n+1} = \sqrt{x_n+2} \end{cases} $$ 

We can find this by showing $x_n$ is contractive.

$$
\begin{align}
|x_{n+2} - x_{n+1}| & = |\sqrt{x_{n+1}+2} - \sqrt{x_n+2}| \\
\xrightarrow{\text{ Apply Conjugate }} & = |\frac{(\sqrt{x_{n+1}+2}-\sqrt{x_n+2}) - (\sqrt{x_n+2}+\sqrt{x_{n+1}+2})}{\sqrt{x_{n+1}+2} + \sqrt{x_n + 2}}| \\
&  = \frac{\sqrt{x_{n+1}- x_n}}{\sqrt{x_{n+1}+2} + \sqrt{x_n + 2}} \leq \frac{1}{2 \sqrt{2}} |x_{n+1}-x_n|
\end{align}
$$
