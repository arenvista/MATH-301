Recall:

$$
	x_n = (1+ \frac{1}{2} + \frac{1}{3} + \dots  + \frac{1}{n}) \text{ is divergent}
$$

How can we show:

$$
	x_n = (1 + \frac{1}{2^p} + \frac{1}{3^p} + \dots  + \frac{1}{n^p}), ~1<p \text{ is convergent}
$$

Solution 1:
Show via [Monotone Convergence](Atomized/H1/Sequences%20Boundedness,%20Algebraic%20Facts,%20Limit%20Laws,%20and%20Monotone%20Convergence.md) that the sequence is bounded above, thus it must be convergent.

$$
	\begin{align}
		x_n = 1 + \frac{1}{2^p} + \frac{1}{3^p} + \dots  + \frac{1}{n^p} & \leq \int_{1}^{\infty} \frac{1}{x^p} \, dx                                    \\
		                                                                 & = \int_{1}^{2} \frac{1}{x^p} \, dx + \int_{2}^{3} \frac{1}{x^p} \, dx + \dots \\
		                                                                 & \geq 1 + \frac{1}{2^p} + \frac{1}{3^p} + \dots
	\end{align}
$$

Recall

$$
	\int_{}^{} \frac{1}{x^p} \, dx = \frac{1}{1-p} x^{1-p} |^{\infty}_1  = \frac{p}{p-1}
$$

Solution 2
Show it's [Cauchy](LecFormated/L12.md#thm-cauchy-converge-criterion#proof-rightarrow) thus must be convergent.

> [!?] Consider, why we can't use the following to continue the reasoning
>
> $$
> \underbrace{ \left\| x_n - x_m \right\|}_{m<n} =
> \frac{1}{(m+1)^p} +
> \frac{1}{(m+2)^p} +
> \dots + \frac{1}{n^p}
> \leq
> \left( \frac{1}{(m+3)^p} \right) \cdot m
> $$

We must bound this above by the corresponding integral:

$$
	\begin{gathered}
		\underbrace{ \left\| x_n - x_m \right\|}_{m<n} =
		\frac{1}{(m+1)^p} +
		\frac{1}{(m+2)^p} +
		\dots + \frac{1}{n^p}
		\\ \leq
		\int_{m}^{m+1} \frac{1}{x^p} \, dx  +
		\int_{m+1}^{m+2} \frac{1}{x^p} \, dx  +
		\dots
		\int_{n-1}^{n} \frac{1}{x^p} \, dx  +
		= \int_{m}^{n} \frac{1}{x^p} \, dx
		\leq  \int_{m}^{\infty} \frac{1}{x^p} \, dx < \epsilon \text{ if } n_\epsilon < m
	\end{gathered}
$$

### Properly Divergent Sequences

Let $x_n$ be a sequence. We define its divergence behavior as follows:

- **Tending to Infinity:** The sequence $x_n$ tends to infinity, written as:
  $$\lim_{n \to \infty} x_n = \infty \text{ if } \forall~ 0 < \alpha, \exists~ k_\alpha \in \mathbb{N} \text{ s.t. } \forall~ k_\alpha \leq n, ~\alpha < x_n$$
- **Tending to Negative Infinity:** The sequence $x_n$ tends to $-\infty$ if $-x_n$ tends to $\infty$.
- **Properly Divergent:** The sequence $x_n$ is considered **properly divergent** if it tends to either $\infty$ or $-\infty$.

### Example:

If $c>1$ then $c^n$ tends to $\infty$:

$$
	\forall~ \alpha>0, \exists~ k_\alpha \ni k_\alpha > \frac{\alpha}{c-1}\cdot 0 = \alpha
$$

Using Bernoulli's inequality, we can expand the sequence:

$$
	\begin{align*}
		c^n & = (1+a)^n   \\
		    & \geq 1 + na \\
		    & > na
	\end{align*}
$$

Therefore, to guarantee that $c^n > \alpha$, we just need to ensure:
$$na > \alpha \implies n > \frac{\alpha}{a}$$

If $x_n$ tends to $\infty$, then $\lim_{n \to \infty} \frac{1}{x_n} = 0$

> [!cor] Implication on $\frac{1}{x_n}$
> If $x_n$ is properly divergent, then $\lim_{n \to \infty} \frac{1}{x_n} = 0$. But the converse is not true.

### Theorem 1: Divergence of Monotone Sequences

A monotone sequence is properly divergent if and only if it is unbounded.

Specifically, this breaks down into two cases:

- **Increasing:** If $x_n$ is an unbounded increasing sequence, then $\lim_{n \to \infty} x_n = \infty$.
- **Decreasing:** If $x_n$ is an unbounded decreasing sequence, then $\lim_{n \to \infty} x_n = -\infty$.

> **Example Application (Geometric Sequence):** > To prove the sequence $c^n$ diverges to $\infty$ (for $c > 1$), we let $c = a + 1$ (where $a > 0$). Because it is an increasing sequence, we just need to prove it is unbounded by finding an $n$ such that $c^n > \alpha$ for any arbitrarily large $\alpha$.

---

### Theorem 2: Direct Comparison Test for Divergent Sequences

Let $x_n$ and $y_n$ be two sequences such that for all sufficiently large $n$, $x_n \leq y_n$.

- **Pushing up:** If $\lim_{n \to \infty} x_n = \infty$, then $\lim_{n \to \infty} y_n = \infty$.
- **Pushing down:** If $\lim_{n \to \infty} y_n = -\infty$, then $\lim_{n \to \infty} x_n = -\infty$.

---

### Theorem 3: Limit Comparison Test for Divergent Sequences

If $x_n$ and $y_n$ are sequences such that their ratio converges to a strictly positive limit, they share the same divergence behavior:

$$
	\lim_{n \to \infty} \frac{x_n}{y_n} = L > 0 \implies (x_n \rightarrow \infty \iff y_n \rightarrow \infty)
$$

_(Note: This also applies to $-\infty$ if the signs of the sequences allow it)._

**Proof:**

Assume $\frac{x_n}{y_n} \rightarrow L > 0$. Let $\epsilon = \frac{L}{2}$.

By the definition of a limit, there exists an index $N > 0$ such that for all $n \geq N$:

$$
	\left| \frac{x_n}{y_n} - L \right| < \frac{L}{2}
$$

By opening the absolute value, we get the bounds:

$$
	-\frac{L}{2} < \frac{x_n}{y_n} - L < \frac{L}{2}
$$

$$
	\frac{L}{2} < \frac{x_n}{y_n} < \frac{3L}{2}
$$

Using these inequalities, we can prove both directions using the Direct Comparison Test (Theorem 2):

1.  **If $x_n \rightarrow \infty$:** Using the right side of the inequality, $x_n < \frac{3L}{2} y_n$. Rearranging this gives $y_n > \frac{2}{3L} x_n$. Since $x_n \rightarrow \infty$, it pushes $y_n$ up to $\infty$ as well.
2.  **If $y_n \rightarrow \infty$:** Using the left side of the inequality, we have $\frac{L}{2}y_n < x_n$. Since $y_n \rightarrow \infty$, it pushes $x_n$ up to $\infty$ as well.

# Limits of Functions

$$
	\lim_{x \to c} f(x)
$$

$$
\begin{gathered}
	\text{If } f(x) :=
	\begin{cases}
		0 < x \implies \frac{1}{x} \\
		x = -1 \implies 1
	\end{cases} \\ \\
\text{Can we define} \lim_{x \to -1/2} f(x)? \implies \text{ we are being to look at values of $f(x)$ where } x \in (0,\infty) \cup \{ -1 \}
\end{gathered}
$$

Define:
Let $\underbrace{A \in \mathbb{R}}_{A \text{ is the domain of f}}$. A point $c \in  \mathbb{R}$ is a ***cluster point*** of $A$ if:
$$
    \forall~ \delta > 0, \exists~  x \neq c \in  A \text{ s.t. } |x-c| < \delta
$$ 

Considering the example above:  For $A = \in (0,\infty) \cup \{ -1 \}$
- The set of cluser points of A is $[0,\infty)$


Thm
$c \in  \mathbb{R}$ is a cluster point of $A$ IFF $\exists~ a_n$ (a sequence) s.t. 
$$
    \lim_{n \to \infty} a_n = c ~\land~ \forall~ n \in \mathbb{N}, a_n \neq c
$$ 

Ex:
- $A$ is finite then there is no cluster points
- $A = \{ n \}$ then there is no cluster point
- $A = \{ \frac{1}{n} \}$ then there is a cluster point, $0$
- $A = (0,1)$ then the cluser points are $[0,1]$

Def
Let $A \subseteq \mathbb{R}$ and $c$ be a cluster point of $A$. Let $f$ be a function on $A$
A number $L$ is said to be a limit of $f$ at $c$ (i.e. $\lim_{x \to c} f(x) = L$). 
If $\forall~ \epsilon > 0, \exists~ \delta_\epsilon > 0$ s.t. $\forall~ x \in A$ and $0 < |x-c| < \delta_\epsilon, ~|f(x)-L|<\epsilon$

If the limit of $f$ at $c$ DNE, we say $f$ diverges at $c$.

Example
$$
\begin{gathered}
\lim_{x \to c} \frac{1}{x} = \frac{1}{c} \text{ if } 0<c \\
x \in \mathbb{R} - \{ 0 \} \implies c \in  \mathbb{R} \\
\end{gathered}
$$ 

Start with $|f(x)-L| < \epsilon$:
$$
\begin{gathered}
|\frac{1}{x} - \frac{1}{c} | < \epsilon  \\
\iff |\frac{x-c}{xc}|  \\
\iff \frac{1}{xc} |x-c| < \epsilon \leftarrow |x-c| < \delta_\epsilon
\end{gathered}
$$ 

Note we want to:
$$
\underbrace{\frac{1}{xc}}_{\text{Bound this by a constant}} |x-c| < \epsilon \leftarrow |x-c| < \delta_\epsilon
$$ 
But we have no way to do so directly, instead observe below:

If $\frac{1}{xc} < D$ then $D|x-c|<\epsilon \implies \frac{1}{xc} |x-c| < \epsilon \leftarrow |x-c| < \delta_\epsilon$

Therewore we must work from: 
$$
|x-c| < \delta_\epsilon \implies 
\begin{cases}
\frac{1}{xc} < D \\
D|x-c|<\epsilon \implies \frac{1}{xc} |x-c| < \epsilon \leftarrow |x-c| < \delta_\epsilon \\
\end{cases} \implies 
\frac{1}{xc} |x-c| < \epsilon
$$ 

So we must find some $\delta_\epsilon$ where $\delta_\epsilon < \frac{c}{D}$ as this inequality is equal to $D|x-c| < \epsilon$

For the second one consider what if $\delta_\epsilon < c$

Observe:
$$
\begin{gathered}
|x-c| < \epsilon/2 \implies \\
c/2 < x < 3c/2 \\
\frac{1}{xc} < \frac{2}{c^2} \\
\text{Note $D$ is defined to be the temperary bound that makes the inequality work}
\end{gathered}
$$ 

### Proof

$$
\forall~ \epsilon>0, \exists~ \delta_\epsilon = min \{ \frac{c}{2}, \frac{c^2\epsilon}{2} \} 
~\forall~ x \in  A, 0<|x-c|<\epsilon_\epsilon
$$ 

$$
\begin{gathered}
\delta_\epsilon < \frac{c}{2} \implies |x-c| < \frac{c}{2}\\
\implies \frac{c}{2} < x < \frac{3c}{2} \\
\implies \frac{1}{xc} < \frac{1}{\frac{c}{2}c} = \frac{2}{c^2} \\
\therefore |\frac{1}{x} - \frac{1}{c}| < \frac{2}{c^2} |x-c| < \frac{2}{c^2}\delta_\epsilon < \frac{2}{c^2} \cdot  \frac{c^2 \epsilon}{2} = \epsilon
\end{gathered}
$$
