# Denumerable
> [!def] 
> ## [Denumerable](1769807964-EKVE.md)
> If the set is *countable* AND *infinite* it is **denumerable**
> ---
> > [!pf]
> > ### Informal Proof: [The set $\mathbb{N} \times \mathbb{N}$ is denumerable. (1.3.8)]
> > *See this [video](https://www.youtube.com/watch?v=0HF39OWyl54) for more context.*
> > **The Goal:**
> > To map all ordered pairs $(m,n)$ where $m,n \in \mathbb{N}$ to a single sequential list:
> > $$(1,1), (1,2), (2,1), (1,3), (2,2), (3,1), (1,4), \dots$$
> >
> > **The Method (Diagonal Map):**
> > We cannot count by rows because rows are infinite. Instead, we generate the list using a **diagonal procedure**:
> > ![diag.png | center | 200](assets/imgs/diag.png)
> >
> > **Step 1: Observe the Diagonal Pattern**
> > Note the number of points in each specific diagonal:
> > - **1st diagonal:** 1 point [(1,1)]
> > - **2nd diagonal:** 2 points [(1,2), (2,1)]
> > - **$k$-th diagonal:** $k$ points
> >
> > To count how many points exist in the first $k$ diagonals combined, we use the triangular number formula $\psi(k)$:
> > $$\psi(k) = 1 + 2 + \dots + k = \frac{k(k+1)}{2}$$
> >
> > **Step 2: Locate a specific point $(m, n)$**
> > To find the exact list position (index) of a pair $(m,n)$:
> > 1.  **Find the Diagonal:** The point lies in the **$(m+n-1)$-th** diagonal.
> > 2.  **Count Previous Points:** We first count all points in the *previous* $m+n-2$ diagonals using the formula above.
> > 3.  **Add Current Offset:** We add $m$ to represent the point's specific position within its own diagonal.
> >
> > **Step 3: The Final Formula**
> > Combining these observations gives the bijection function $h(m,n)$:
> > $$h(m,n) = \frac{(m+n-2)(m+n-1)}{2} + m$$
