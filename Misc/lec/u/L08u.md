### Bounded Sequences

A sequence $X=(x_n)$ of real numbers is said to be **bounded** if there exists a real number $M>0$ such that $|x_n|<M$ for all $n \in \mathbb{N}$.

**Prove:** If $C > 1$, then $C^m > C^n \iff m>n$

> **Proof by Induction (Showing $C^{n+1} > C^n$)**
> Base case: Since $C>1$, multiplying by $C$ gives $C^2 > C^1$.
> Suppose $C^{k+1} > C^k$.
> Multiplying both sides by $C$ gives $C^{k+1} \cdot C > C^k \cdot C$, which simplifies to $C^{k+2} > C^{k+1}$.
> Therefore, for all $n \in \mathbb{N}$, $C^{n+1} > C^n$.

> **Proof by Contradiction (Showing $m>n$ if $C^m > C^n$)**
> Suppose $C^m > C^n$. We want to show $m>n$.
> * **Case 1 ($m=n$):** This would mean $C^m = C^n$, which is a contradiction.
> * **Case 2 ($m<n$):** Based on our induction proof, this would imply $C^m < C^n$, which contradicts our supposition.
> Therefore, $m>n$.

### Limits of Products and Reciprocals

**Recall standard limit definitions:**

* $|x_n - x| < \epsilon$ if $n > N_{\epsilon}$
* $|y_n - y | < \xi$ if $n > N_{\xi}$

**Prove:** $\lim_{n \to \infty} x_n y_n = xy$

> **Backwards Search (Scratchwork):**
> We want to show $|x_n y_n - xy| < \epsilon$.
> 
> $$\begin{aligned} |x_n y_n - xy| &= |x_n y_n - x_n y + x_n y - xy| \\ &= |x_n(y_n-y) + y(x_n -x)| \\ &\leq |x_n||y_n - y| + |y||x_n-x| \end{aligned}$$
> 
> 
> 
> We want to bound both terms by $\frac{\epsilon}{2}$.
> To do this, notice that since $x_n$ is convergent, it has a bound $M$ such that $|x_n| \leq M$ for all $n \in \mathbb{N}$.
> Thus, we need $|y_n -y| < \frac{\epsilon}{2M}$ and $|x_n-x| < \frac{\epsilon}{2|y|}$ (assuming $y \neq 0$).

**Forward Logic:**

* **Case 1: $y \neq 0$**
Because $x_n$ is convergent, it is bounded. Therefore, there exists $M > 0$ such that $|x_n| \leq M$ for all $n \in \mathbb{N}$.
Since $y_n \to y$, for all $\epsilon > 0$, there exists $N_y \in \mathbb{N}$ such that for all $n \geq N_y$:

$$|y_n -y| < \frac{\epsilon}{2M}$$



Since $x_n \to x$ and $y \neq 0$, there exists $N_x \in \mathbb{N}$ such that for all $n \geq N_x$:

$$|x_n -x| < \frac{\epsilon}{2|y|}$$



Let $V = \max\{N_x, N_y\}$. For all $n \geq V$:

$$|x_n y_n - xy| \leq |x_n||y_n -y| + |y||x_n -x| < M\left(\frac{\epsilon}{2M}\right) + |y|\left(\frac{\epsilon}{2|y|}\right) = \epsilon$$


* **Case 2: $y = 0$**
We want to show $|x_n y_n - 0| < \epsilon$.
Since $|x_n| \leq M$, we need $M|y_n| < \epsilon$, which means $|y_n| < \frac{\epsilon}{M}$.
Since $y_n \to 0$, we can choose $N$ such that for all $n \geq N$, $|y_n - 0| < \frac{\epsilon}{M}$. Thus, $|x_n y_n| < \epsilon$.

**Prove:** $\lim_{n \to \infty} \frac{1}{y_n} = \frac{1}{y}$

> **Scratchwork:** > We want $\left|\frac{1}{y_n} - \frac{1}{y}\right| < \epsilon$, which simplifies to $\frac{|y-y_n|}{|y_n||y|} < \epsilon$.
> To bound the denominator away from zero, we need to guarantee that $|y_n|$ is sufficiently large. We can pick a bound of $\frac{|y|}{2}$.

**Formal Proof:**
Consider the subproblem where $\lim_{n \to \infty} y_n = y$.
Let $\epsilon_0 = \frac{|y|}{2}$. There exists $N_1 \in \mathbb{N}$ such that for all $n \geq N_1$, $|y_n - y| < \frac{|y|}{2}$.
By the reverse triangle inequality:


$$|y| = |y - y_n + y_n| \leq |y_n - y| + |y_n|$$
$$|y_n| \geq |y| - |y_n - y| > |y| - \frac{|y|}{2} = \frac{|y|}{2}$$


Now we have a bound:

$$\left|\frac{1}{y_n} - \frac{1}{y}\right| = \frac{|y_n-y|}{|y_n||y|} \leq \frac{|y_n-y|}{\left(\frac{|y|}{2}\right)|y|} = \frac{2}{|y|^2} |y_n-y|$$

Since $y_n \to y$, there exists $N_2 \in \mathbb{N}$ such that for all $n \geq N_2$:

$$|y_n - y| < \frac{|y|^2}{2}\epsilon$$

Let $N = \max\{N_1, N_2\}$. For all $n \geq N$:

$$\left|\frac{1}{y_n}-\frac{1}{y}\right| \leq \frac{2}{|y|^2} |y_n - y| < \frac{2}{|y|^2} \left(\frac{|y|^2}{2}\epsilon\right) = \epsilon$$

## 3.3 Monotonic Sequences

**Definition: Monotonic Sequence**
Let $X=(x_n)$ be a sequence.

* $X$ is **increasing** if it satisfies: $x_1 \leq x_2 \leq x_3 \leq \dots \leq x_n \leq \dots$
* $X$ is **decreasing** if it satisfies: $x_1 \geq x_2 \geq x_3 \geq \dots \geq x_n \geq \dots$
* $X$ is **monotonic** if it is either increasing or decreasing.

**Theorem: Monotonic Convergence Theorem**
A monotonic sequence is convergent if and only if it is bounded.

* **Case 1:** If $X$ is bounded and increasing $\implies \lim_{n \to \infty} x_n = \sup \{x_n \mid n \in \mathbb{N}\}$
* **Case 2:** If $X$ is bounded and decreasing $\implies \lim_{n \to \infty} x_n = \inf \{x_n \mid n \in \mathbb{N}\}$

> **Proof for Case 2 (Decreasing):**
> If $X$ is bounded and decreasing, then $-X := (-x_n)$ is bounded and increasing.
> By Case 1:
> 
> $$\lim_{n \to \infty} (-x_n) = \sup \{-x_n \mid n \in \mathbb{N}\}$$
> 
> 
> $$-1 \cdot \lim_{n \to \infty} x_n = -1 \cdot \inf \{x_n \mid n \in \mathbb{N}\}$$
> 
> 
> $$\lim_{n \to \infty} x_n = \inf \{x_n \mid n \in \mathbb{N}\}$$
> 
> 

> **Proof for Case 1 (Increasing):**
> Let $x = \sup \{x_n \mid n \in \mathbb{N}\}$. We must show $x_n \to x$, meaning $|x_n - x| < \epsilon$, which is equivalent to $x-\epsilon < x_n < x+\epsilon$.
> Note that $x_n \leq x < x+\epsilon$ for all $n \in \mathbb{N}$ since $x$ is an upper bound.
> However, $x-\epsilon$ is *not* an upper bound of $X$ (since $x$ is the least upper bound).
> Therefore, there exists $N \in \mathbb{N}$ such that $x_N > x-\epsilon$.
> Because the sequence is increasing, for all $n \geq N$, we have $x_n \geq x_N > x-\epsilon$.
> Thus, for all $n \geq N$, $x-\epsilon < x_n < x+\epsilon$, which means $|x_n - x| < \epsilon$.

### Example Application

Let $X=(x_n)$ be defined as $x_1=1$ and $x_{n+1} = \sqrt{2 x_n}$ for all $n \in \mathbb{N}$. Show $\lim_{n \to \infty} x_n = 2$.

*Observe the first terms:* $x_1 = 1, x_2 = \sqrt{2}, x_3 = \sqrt{2 \sqrt{2}}$

**Step 1: Prove by induction $X$ is increasing.**

* Base Case ($n=1$): $x_2 = \sqrt{2} \geq 1 = x_1$
* Inductive Step: Suppose $x_k \leq x_{k+1}$. We want to show $x_{k+1} \leq x_{k+2}$.

$$x_{k+1} = \sqrt{2 x_k}$$


$$x_{k+2} = \sqrt{2 x_{k+1}}$$



Since $x_k \leq x_{k+1}$, it follows that $2x_k \leq 2x_{k+1}$, and therefore $\sqrt{2x_k} \leq \sqrt{2x_{k+1}}$, which means $x_{k+1} \leq x_{k+2}$.

**Step 2: Show $X$ is bounded above by 2.**

* Base Case ($n=1$): $x_1 = 1 < 2$
* Inductive Step: Suppose $x_k \leq 2$.

$$2x_k \leq 4 \implies \sqrt{2x_k} \leq \sqrt{4} \implies x_{k+1} \leq 2$$



Since $X$ is increasing and bounded, it converges to $x = \sup X$.

**Step 3: Find the limit.**


$$\lim_{n \to \infty} x_{n+1} = x \quad \text{and} \quad \lim_{n \to \infty} \sqrt{2 x_n} = \sqrt{2x}$$

$$x = \sqrt{2x}$$

$$x^2 = 2x \implies x(x-2) = 0$$


The roots are $x=0$ or $x=2$.
Because the sequence is increasing and starts at $x_1=1$, $x$ cannot be $0$.
Therefore, $x = 2$.
