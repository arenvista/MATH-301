# Completeness Property

Recall: To verify a number is a sumpremum we must confirm two things:

- The number is an upper bound
- It is the least upper bound

> We can prove this by showing any upper bound is greater than or equal to the value or any number less than it is not an upper bound.

Suppose $u$ is a supremum of $S$:

- $\forall ~v < u, \exists ~s_v \in S \text{ s.t. } v < s_v$
- Note the statement above is negation of the statement:
- $\forall ~s \in S, s \leq v$ (what we are disproving).
- Note $\exists ~s_v \in S \text{ s.t. } v < s_v$ qualifies that $v$ is not an upper bound of $S$
- Note we can also rewrite $v$ as $v=u-\epsilon$

## Example:

# Shifted Set Supremum
> [!ex] Shifted Set Supremum
>
> - Let $S \neq \emptyset, S \in \mathbb{R}$.
> - Define the shifted $S$ by $a$ as $a+S = \{ s+a | s \in S \}$
>   **$$ \text{This implies the following: } \sup (a+S) = a + \sup S$$**
>   > [!pf] Proof: $\sup (a+S) = a + \sup S$
>   >
>   > > [!case] _Case 1:_ $a + \sup S$ is an upper bound of $a+S$
>   > > Goal: Show $\forall ~a+s \in a+S, ~~a+s \leq  a + \sup S$ holds.
>   > > Approach (Backward Search):
>   > >
>   > > 1. $\iff$ Show $s \leq \sup S$
>   > > 2. $\iff$ $\sup S$ is the smallest upper bound of $S$
>   > > 3. $\iff$ $\sup S$
>   > >
>   > > ***
>   > >
>   > > Formally:
>   > >
>   > > 1. Since $\sup S$ is a sumpremum, by definition:
>   > > 2. $\sup S$ is an upper bound of $S \implies \forall ~s \in S, s \leq \sup S$
>   > > 3. Naturally adding $a$ to both sides of the inequality yields: $s+a \leq a + \sup S$
>   > > 4. Thus $a + \sup S$ is an **upper bound** of $a+S$
>   >
>   > > [!case] _Case 2:_ $a + \sup S$ is the least upper bound of $a+S$
>   > > Goal: Show $\forall ~v$ where $v$ is an upper bound of $S+a$, $a + \sup S \leq v$
>   > > Approach (Backwards Search):
>   > >
>   > > 1. $\iff S+a$, $a + \sup S \leq v$
>   > > 2. $\iff \sup S \leq  v-a$
>   > > 3. $\iff v-a$ is an upper bound of $S$
>   > > 4. $\iff \forall ~s \in S, s \leq v-a$
>   > > 5. $\iff \forall ~s \in S, a+s \leq v$
>   > > 6. $v$ is an upper bound of $a+S$
>   > >
>   > > ***
>   > >
>   > > Formally:
>   > >
>   > > 1. By supposition $v$ is an upper bound of $a+S$.
>   > > 2. $\implies \forall ~s \in S, a+s \leq v$
>   > > 3. $\implies \forall ~s \in S, s \leq v-a$
>   > > 4. $\implies v-a$ is an upper bound of $S$
>   > > 5. $\implies \sup S \leq  v-a$
>   > > 6. $\implies S+a$, $a + \sup S \leq v$
>   >
>   > **Conclusion:** Now hw have shown $a+\sup S$ is both an upper bound of $a+S$ and is the smallest possible upper bound. Thus, we have defined $\sup(a+S) = a + \sup S$

# Scaled Set Supremum
> [!imp] Scaled Set Supremum (Practice)
> Consider the set $aS = \{ as | s \in S \}$.
>
> > [!note] Def. $\sup(aS)$
> >
> > $$
> > 	\sup(aS) =
> > 	\begin{cases}
> > 		a\sup S & \text{If } a > 0 \\
> > 		a\inf S & \text{If } a < 0
> > \end{cases}
> > $$

## Example

> [!ex]
> **Prove:** If $\forall ~a \in A, b \in B, a \leq b \implies \sup A \leq \inf B$
> Approach:
>
> 1. $\sup A \leq \inf B$
> 2. $\inf B$ is an upper bound of $A$
> 3. $\forall ~a \in A, a \leq \inf B$
> 4. $\forall ~ a \in A, a$ is a lower bound of $B$
> 5. $\forall ~b \in B \land \forall ~a \in A, a \leq b$
>
> ---
>
> 1. $\iff$ By proposition $\forall ~a \in A, b \in B, a \leq b$
> 2. $\iff$ $\forall ~ a \in A, a$ is a lower bound of $B$
> 3. $\iff$ $\forall ~a \in A, a \leq \inf B$
> 4. $\iff$ $\inf B$ is an upper bound of $A$
> 5. $\iff$ $\sup A \leq \inf B$

## Completeness Property of $\mathbb{R}$
> [!def] Completeness Property of $\mathbb{R}$
> $\forall ~A \subseteq \mathbb{R}, A \neq \emptyset$ that has an upper or lower bound then $A$ has a supremum or infimum in $\mathbb{R}$

> [!thm] Archimedean Property
> $$\text{Simply states: } x \in \mathbb{R} \implies \exists ~n_x \in \mathbb{N} \ni x \leq  n_x$$
>
> > [!pf] Proof:
> > Suppose for the sake of contradiction $x \in \mathbb{R} \implies \forall ~n_x \in \mathbb{N}, x > n_x$.
> >
> > Consider:
> >
> > 1. $\forall ~n_x \in \mathbb{N}, x > n_x$
> > 2. $x$ is an upper bound of $\mathbb{N}$, which is a subset of $\mathbb{R}$
> > 3. By the completeness property given an upper bound exists, there must be a supremum in $\mathbb{R}$
> > 4. So $\sup \mathbb{N} -1$ is not an upper bound of $\mathbb{N}$
> > 5. So $\exists ~m \in \mathbb{N} \ni \sup \mathbb{N}-1 < m$
> > 6. So $\sup \mathbb{N} < m+1$
> > 7. Note that $m+1 \in \mathbb{N}$, this is a contradiction to the definition of a supremum.
>
> > [!cor] If $S= \{ \frac{1}{n} | n \in \mathbb{N} \}$ then $\inf S = 0$.
> >
> > > [!pf] Proof:
> > > 
> > > We must satsify two conditions:
> > > 
> > > 1.  $0$ is a lower bound
> > > 2.  $0$ is the largest lower bound
> > > 
> > > > [!case] $0$ is a lower bound
> > > > 
> > > > Prove: $n>0 \implies \frac{1}{n} > 0$
> > > > Consider contradiction: $n>0 \implies \frac{1}{n} \leq 0$
> > > > 
> > > > $$
> > > > \begin{aligned}
> > > >      & \frac{1}{n} \leq  0                           \\
> > > >      & \implies \frac{1}{n} \cdot n \leq  0  \cdot n \\
> > > >      & \implies 1 \leq  0                            \\
> > > > \end{aligned}
> > > > $$
> > > > $$ \text{Thus 0 is a lower bound.} $$
> > > 
> > > > [!case] $0$ is the largest lower bound
> > > > $\forall ~\epsilon>0$ we shouw that $\epsilon$ is not a lower bound of $S$
> > > > 1. Since $\frac{1}{\epsilon} \in \mathbb{R}$ 
> > > > 2. By the Archimedian Property $\exists ~n \in \mathbb{N} \ni \frac{1}{n} < \epsilon$a
> > > > 3. So $\epsilon$ is not a lower bound of $S$
> > 
> > By Case 1,2 $\inf S = 0$
>
> > [!cor] If $\forall ~t \in \mathbb{R} \ni t>0, \exists ~n \in \mathbb{N} \ni 0 < \frac{1}{n} < t$
> > Expansion of prior corollary
> 
> >[!cor] If $\forall ~y \in \mathbb{R}, y>0, \exists ~n \in \mathbb{N} \ni n-1 \leq y < n$
> > For any real number it can be bounded by two natural numbers
> > 
> > Consider $E = \{ m \in \mathbb{N} | y < m \}$
> > 
> > Note: by Archimedian Property $\implies E \neq \emptyset$
> > 1. $E$ has a smalled element, denoted by $n_y$.
> > 2. So $y < n_y$ 
> > 3. $n_y-1 \not \in E \implies  n_y -1 \leq y$
